═══════════════════════════════════════════════════════════════
THE CORE IDEA SHIFT
═══════════════════════════════════════════════════════════════

OLD THINKING (wrong):
  Worker → one video → one test → KaamCard → done

NEW THINKING (correct):
  Worker joins → browses a catalogue of assessments like Coursera
  → attempts any test or video assessment they want
  → earns individual Skill Certificates for each passed assessment
  → KaamCard is a GPA-style summary that gets smarter 
    and more credible as they attempt more assessments
  → the more assessments taken, the more trustworthy the score
  → workers can see how many others attempted each test
    (like Coursera showing "47,000 learners enrolled")

PART 2 — BACKEND: UPDATED SCORING LOGIC
═══════════════════════════════════════════════════════════════

UPDATE compute-score endpoint logic:

videoScore:
  = average of ALL VideoAssessment scores for this worker
    where status = SCORED
  If no videos scored yet = 0

testScore:
  = average of ALL TestSubmission rawScores for this worker
    where status = COMPLETED
  Each test counts once as its BEST score (if retaken, 
  use highest score for that testId)

workHistoryScore:
  = computed from WorkHistory entries (existing logic)

finalScore:
  = (videoScore × 0.35) + (testScore × 0.45) 
    + (workHistoryScore × 0.20)

credibilityLevel:
  totalAssessments = totalTestsTaken + totalVideosTaken
  1-3   → EMERGING
  4-8   → ESTABLISHED
  9+    → EXPERT (credibility level, different from tier)

KaamCard update logic:
  - NEVER delete old KaamCard
  - UPDATE existing KaamCard with new scores
  - CREATE KaamCardHistory entry for every update
  - Increment version number

Auto-trigger compute-score when:
  - A VideoAssessment is scored by admin
  - A TestSubmission is completed (after Groq evaluation)
  So worker never has to manually click "compute score" —
  KaamCard updates automatically in the background

UPDATE submit-test endpoint:
  After Groq evaluation completes:
  1. Save TestSubmission with score
  2. Increment TradeTest.totalAttempts by 1 (platform counter)
  3. If score >= passingScore (default 60):
     - Create SkillCertificate
     - Generate certificate PDF
     - Generate certificateNo: "7K-[TRADE]-[YEAR]-[5DIGITS]"
       e.g. "7K-ELEC-2025-00142"
  4. Trigger compute-score in background (async)
  5. Check if this is first passing test AND worker has 
     at least one video → if so, issue KaamCard if not exists
  6. Return: { score, certificateEarned, certificate, 
               kaamCardUpdated, newKaamCardScore }

NEW endpoints needed:
  GET /api/v1/tests/catalogue
    Query: trade, category, difficulty, language, search
    Returns: tests grouped by category with:
      { category, tests: [ { ...test, 
        workerBestScore, workerAttempts, certificateEarned,
        totalAttempts (platform-wide) } ] }

  GET /api/v1/workers/:id/certificates
    Returns all SkillCertificates for worker

  GET /api/v1/workers/:id/video-assessments
    Returns all VideoAssessment records for worker

  GET /api/v1/workers/:id/kaamcard/history
    Returns KaamCardHistory entries for score progression chart
