
## SCORING ENGINE (services/scoringEngine.js)

computeWorkHistoryScore(workHistories):
  - If no entries: return 0
  - base = average of all ratings mapped to 0-100 scale: ((avg - 1) / 4) * 100
  - bonus = verified entries * 5 (max bonus = 15)
  - return Math.min(100, base + bonus)

computeFinalScore(videoScore, testScore, workHistoryScore):
  return (videoScore * 0.35) + (testScore * 0.45) + (workHistoryScore * 0.20)

computeTier(finalScore):
  if >= 80 → EXPERT
  if >= 60 → GOLD  
  if >= 40 → SILVER
  else     → BRONZE

mockVideoScore():
  return Math.floor(Math.random() * 40) + 55  // 55-95 realistic range
