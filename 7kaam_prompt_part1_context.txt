## THE PLATFORM — 7 KAAM

Workers (electricians, plumbers, carpenters, AC technicians, painters, 
welders) are certified through a 3-signal AI scoring pipeline:

Signal 1 — Skill Video (35% weight)
  - Worker uploads a 60-second skill demonstration video
  - Stored on Supabase Storage (free, built-in)
  - Scored by a mock computer vision function for now
    (return a realistic random score 55-95, mark as TODO for real CV later)

Signal 2 — Trade Test (45% weight)  
  - Worker takes a 10-question trade-specific test
  - Delivered via the Admin Dashboard web UI (NOT WhatsApp — dropped)
  - Test answers evaluated by GROQ API (free tier)
  - Use model: llama3-8b-8192
  - Groq API endpoint: https://api.groq.com/openai/v1/chat/completions
  - Evaluation prompt: score each answer 0-10, return structured JSON

Signal 3 — Work History (20% weight)
  - Admin enters employer name, rating (1-5), tenure dates
  - Score computed: avg(ratings) normalized to 0-100 + verified bonus

Final Score = (VideoScore × 0.35) + (TestScore × 0.45) + (WorkHistory × 0.20)

Tier:
  0–39   → BRONZE
  40–59  → SILVER  
  60–79  → GOLD
  80–100 → EXPERT

Output: KaamCard — verified certificate with score/100, tier badge,
sub-skill breakdown, and a QR code linking to public verification page.

## ALL BACKEND API ROUTES

Prefix all routes with /api/v1/

### Auth
POST   /api/v1/auth/login          → JWT login for admin
POST   /api/v1/auth/refresh        → refresh access token
POST   /api/v1/auth/logout

### Workers  
POST   /api/v1/workers             → onboard new worker
GET    /api/v1/workers             → list (filters: trade, city, tier, status, search)
GET    /api/v1/workers/:id         → full worker detail
PATCH  /api/v1/workers/:id         → update worker
DELETE /api/v1/workers/:id         → soft delete (set status SUSPENDED)

### AI Scoring Pipeline
POST   /api/v1/workers/:id/upload-video       → get Supabase Storage presigned URL
POST   /api/v1/workers/:id/score-video        → mock CV scorer, save videoScore
POST   /api/v1/workers/:id/submit-test        → submit answers, trigger Groq evaluation
POST   /api/v1/workers/:id/add-work-history   → add employer entry
POST   /api/v1/workers/:id/compute-score      → fuse 3 signals, compute tier
POST   /api/v1/workers/:id/issue-kaamcard     → generate PDF + QR, upload to Supabase

### Trade Tests
POST   /api/v1/tests               → create test
GET    /api/v1/tests               → list tests
GET    /api/v1/tests/:id           → get test with questions
PATCH  /api/v1/tests/:id           → update/toggle active
DELETE /api/v1/tests/:id

### KaamCards
GET    /api/v1/kaamcards           → all kaamcards (admin)
GET    /api/v1/kaamcards/:workerId → get worker's latest kaamcard
POST   /api/v1/kaamcards/:id/revoke → revoke with reason
GET    /api/v1/verify/:qrToken     → PUBLIC — verify kaamcard by QR token (no auth)

### Analytics
GET    /api/v1/analytics/overview         → totals, avg score, tier split
GET    /api/v1/analytics/by-trade         → breakdown per trade
GET    /api/v1/analytics/by-city          → breakdown per city
GET    /api/v1/analytics/score-distribution → histogram data
GET    /api/v1/analytics/certifications-over-time → daily certs (last 30 days)

### Mobile App (stub — implemented but returns mock data for now)
GET    /api/v1/mobile/workers/nearby       → workers by location + trade filter
GET    /api/v1/mobile/workers/:id/public   → public worker profile
POST   /api/v1/mobile/bookings             → create booking
GET    /api/v1/mobile/bookings/:id         → get booking
POST   /api/v1/mobile/customers/register   → register customer

## GROQ EVALUATOR (services/groqEvaluator.js)

Use Groq free API with model: llama3-8b-8192

System prompt:
"You are an expert trade certification evaluator for Indian blue-collar workers.
Evaluate the worker's answers strictly and fairly. Return ONLY valid JSON, 
no markdown, no explanation outside the JSON."

User prompt template:
"Trade: {trade}
Test Title: {testTitle}
Questions and Worker Answers:
{questions.map((q, i) => `Q${i+1}: ${q.question}
Correct Answer: ${q.correctAnswer}
Worker Answer: ${answers[i]}`).join('\n\n')}

Return this exact JSON:
{
  \"totalScore\": <number 0-100>,
  \"breakdown\": [
    {\"question\": \"...\", \"workerAnswer\": \"...\", \"score\": <0-10>, \"feedback\": \"...\"}
  ],
  \"overallFeedback\": \"...\"
}"

Wrap in try/catch — if Groq fails, return a mock score with a note.
