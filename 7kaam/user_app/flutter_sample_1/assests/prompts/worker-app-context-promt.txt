You are a senior Flutter developer. Build a complete Flutter mobile 
application called "7 Kaam — Worker App" from scratch.

## OVERVIEW
7 Kaam is an AI-powered skill certification platform for blue-collar 
workers in India. This app is for WORKERS — electricians, plumbers, 
carpenters, AC technicians, painters, welders.

Workers use this app to:
- Register themselves OR login if already onboarded by admin
- Complete their certification pipeline (video + trade test)
- View and share their KaamCard
- Track their score and tier
- Manage their profile and work history

## BACKEND
The backend is already built — Node.js + Express REST API.
Base URL: http://localhost:8000/api/v1  (update to production URL later)

All API calls use JWT Bearer token in Authorization header.
Token is stored in Flutter SecureStorage after login.

## EXISTING BACKEND ENDPOINTS TO USE

Auth:
POST /api/v1/workers/register     → self-register new worker
POST /api/v1/auth/worker/login    → phone number + OTP login
POST /api/v1/auth/refresh         → refresh JWT token

Worker Profile:
GET  /api/v1/workers/:id          → get full worker profile
PATCH /api/v1/workers/:id         → update profile

Scoring Pipeline:
POST /api/v1/workers/:id/upload-video      → get presigned URL, upload video
POST /api/v1/workers/:id/score-video       → trigger video scoring
POST /api/v1/workers/:id/submit-test       → submit trade test answers
POST /api/v1/workers/:id/add-work-history  → add employer entry
POST /api/v1/workers/:id/compute-score     → compute final score
POST /api/v1/workers/:id/issue-kaamcard    → issue KaamCard

Trade Tests:
GET  /api/v1/tests?trade=ELECTRICIAN&language=HINDI → get available tests

KaamCard:
GET  /api/v1/kaamcards/:workerId  → get worker's KaamCard
GET  /api/v1/verify/:qrToken      → public verify (no auth)

Work History:
POST /api/v1/workers/:id/add-work-history

## FLUTTER PACKAGES TO USE
- dio: HTTP client with interceptors
- flutter_secure_storage: JWT token storage
- provider or riverpod: state management (use Riverpod)
- go_router: navigation
- image_picker: profile photo and video upload
- camera: in-app camera for 60-sec video recording
- qr_flutter: display QR code on KaamCard screen
- flutter_animate: smooth animations
- google_fonts: use Poppins font
- cached_network_image: worker photos
- shimmer: loading skeletons
- file_picker: document uploads
- permission_handler: camera and storage permissions
- intl: date formatting
