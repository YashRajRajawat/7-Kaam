1. SYSTEM ARCHITECTURE OVERVIEW
================================================================================
7 Kaam is a dual-application monorepo designed for certifying Indian skilled/blue-collar
workers (electricians, plumbers, carpenters, AC technicians, painters, welders) through a
3-signal AI evaluation pipeline and issuing verifiable digital credential cards ("KaamCards").

Architecture Stack:
  ├── Backend (Node.js REST API)
  │     ├── Framework: Express.js (v5.2.1)
  │     ├── Database ORM: Prisma ORM (v7.9.0) with PostgreSQL
  │     ├── Authentication: JWT (Access & Refresh tokens), bcryptjs password hashing
  │     ├── AI Evaluation Service: Groq API (llama-3.1-8b-instant LLM for trade test grading)
  │     ├── File Storage: Supabase Cloud Storage JS SDK (for profile pictures and video storage)
  │     ├── Digital Card Generation: pdf-lib (PDF creation) & qrcode (QR Token generation)
  │     └── Task/Queue System: BullMQ + Redis (infrastructure-ready dependencies)
  │
  └── Dashboard Frontend (Admin & Operator Web Portal)
        ├── Framework: Next.js 14 (App Router) & React 18
        ├── Language: TypeScript & Node.js
        ├── Styling: Tailwind CSS & Radix UI Primitives
        ├── Data Fetching & State: TanStack React Query (v5), Axios with auto-JWT refresh, Zustand
        ├── Visualizations: Recharts (Charts for analytics & score distribution)
        └── Icons: Lucide-React

Scoring & Certification Pipeline (3-Signal Fusion Engine):
  1. Signal 1 - Video Practical Analysis (35% weight): Practical demonstration scoring.
  2. Signal 2 - Trade Test Assessment (45% weight): AI-evaluated trade knowledge test using Groq LLM.
  3. Signal 3 - Verified Work History (20% weight): Peer/employer ratings and verified job records.
  ──> Weighted Fusion Engine computes Final Score (0–100) and assigns Tier:
      • EXPERT:  Score >= 80
      • GOLD:    Score >= 60 & < 80
      • SILVER:  Score >= 40 & < 60
      • BRONZE:  Score < 40

5. END-TO-END DATA & VERIFICATION FLOW
================================================================================
1. Worker Onboarding:
   • Operator submits worker info + photo via Next.js `/workers/new`.
   • Backend hashes Aadhaar (`SHA-256`), stores profile photo via `supabaseStorage.js`, and creates record in PostgreSQL with `status: PENDING`.

2. 3-Signal Certification Pipeline (`/workers/[id]`):
   • Signal 1 (Video): Operator uploads video of worker performing trade task. Evaluated and scored (35% weight).
   • Signal 2 (Trade Test): Worker answers trade assessment questions. Express backend calls `groqEvaluator.js` using Groq API (`llama-3.1-8b-instant`) to score answers and return detailed feedback (45% weight).
   • Signal 3 (Work History): Employment entries & ratings are added and scored (20% weight).
   • Final Computation: Backend runs `scoringEngine.js`, calculates `finalScore`, assigns `tier` (EXPERT/GOLD/SILVER/BRONZE), and updates worker status to `ACTIVE`.

3. KaamCard Issuance & Verification:
   • Backend generates a PDF credential (`kaamCardGenerator.js`) and a unique QR Token (`qrService.js`).
   • Public users or employers scanning the QR code hit `GET /api/v1/verify/:qrToken` or mobile endpoint `GET /api/v1/mobile/workers/:id/public` to confirm certificate authenticity in real time.
