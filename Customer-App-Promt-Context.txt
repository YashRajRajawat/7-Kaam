You are a senior Flutter developer. Build a complete Flutter mobile 
application called "7 Kaam — Customer App" from scratch.

## OVERVIEW
7 Kaam is an AI-powered skill certification platform for India.
This app is for CUSTOMERS — people who want to find, verify, 
and book certified blue-collar workers (electricians, plumbers, 
carpenters, AC technicians, painters, welders) near them.

Design inspiration: Airbnb (discovery + map toggle) and 
Zomato (list cards, filters, smooth UX). 
India-first design — clean, fast, works on mid-range Android phones.

## BACKEND
Base URL: http://localhost:8000/api/v1
JWT Bearer token in Authorization header after login.

## BACKEND ENDPOINTS TO USE

Auth:
POST /api/v1/mobile/customers/register  → register customer
POST /api/v1/auth/customer/login        → phone + OTP login

Discovery:
GET /api/v1/mobile/workers/nearby
  Query params: 
    trade (optional), tier (optional), 
    city (required), search (optional),
    page, limit
  Returns: list of workers with scores and KaamCard info

Worker Profile (public):
GET /api/v1/mobile/workers/:id/public
  Returns: worker name, trade, city, score, tier, 
           scoreBreakdown, kaamCardUrl, qrToken, 
           workHistories (employer names + ratings only)

KaamCard Verify (public, no auth):
GET /api/v1/verify/:qrToken

Bookings:
POST /api/v1/mobile/bookings            → create booking
GET  /api/v1/mobile/bookings/:id        → get booking detail
GET  /api/v1/mobile/customers/:id/bookings → customer's bookings

        Star-style score display: ★ 87/100
        Tier badge: EXPERT (teal) / GOLD (gold) / SILVER (gray)

        Three mini score pills: 
          🎥 82  📝 91  💼 78

MAP VIEW (toggle):

    GOLD → gold pin

    Tap bottom sheet card → Worker Detail Screen
